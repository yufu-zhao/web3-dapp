# 链构（ChainForge）路线图

这里维护跨应用的唯一进度状态。每项都应有可检查的完成条件；不要在应用 README 中重复维护相同状态。

状态定义：

- 待开发：尚未开始，且范围或验收条件已明确。
- 开发中：已有明确负责人和进行中的实现。
- 已完成：实现和对应验收均已通过。
- 待优化：功能已交付，仍有明确的质量、体验或维护改进项。

| 范围                             | 事项                                                               | 状态   | 验收条件                                                                                                                                                       |
| -------------------------------- | ------------------------------------------------------------------ | ------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 用户端 apps/user                 | Vue、Quasar、TypeScript 骨架与只读安装身份展示                     | 开发中 | GET /public/config 返回数据库中的系统身份，名称和代币信息随安装配置显示                                                                                        |
| 管理后台 apps/admin              | 初始化/迁移状态引导、登录、权限主布局、四类管理页和分页表格组件    | 开发中 | 初始化、待迁移状态可引导；登录/登出与服务端权限校验有效；管理员、系统菜单、角色 CRUD 和系统设置可用；表格支持快捷/高级搜索、刷新、分页、插槽及加载/空/错误状态 |
| 可视化安装器 apps/installer      | 四路由安装流程、数据库初始化、完整合约部署计划与完成摘要           | 开发中 | 部署页钱包切换需用户确认，切回原状态自动撤销待同步；ChainId 在完整部署成功后写入数据库，未完成部署按临时记录限制同链续跑；真实钱包签名与回执恢复待链上验收     |
| 业务 API services/api            | NestJS、Fastify 服务、安装状态、管理认证/权限与 CRUD API、索引任务 | 开发中 | 初始化接口仅返回状态和公开身份；管理员登录会话、权限检查、管理员/菜单/角色 CRUD 和系统设置接口已实现；GET /init 返回成功；索引入口可独立构建并正常退出         |
| 安装器服务 services/installer    | NestJS、Fastify、PostgreSQL、合约包和按链部署资料接口              | 开发中 | 自动建库、非空库确认、已有管理员保护；首次安装按序迁移，已有安装可由本机安装器应用待执行迁移；ChainId 部署锁定与合约部署仍按原链上验收计划进行                 |

| 钱包组件 packages/wallet-connect | Vue 钱包方式选择、多注入钱包发现和按 project_id 启用 WalletConnect | 开发中 | 注入钱包列表滚动与 project_id 条件显示已实现；真实浏览器扩展、WalletConnect 手机端和账户/网络变化待钱包验收                                                    |

| 全部应用                         | 后续业务需求拆解                                                   | 待开发 | 按产品需求确定页面、API、数据、权限和验收条件后再拆分任务                                                                                                      |
