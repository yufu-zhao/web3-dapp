# 链构（ChainForge）路线图

这里维护跨应用的唯一进度状态。每项都应有可检查的完成条件；不要在应用 README 中重复维护相同状态。

状态定义：

- 待开发：尚未开始，且范围或验收条件已明确。
- 开发中：已有明确负责人和进行中的实现。
- 已完成：实现和对应验收均已通过。
- 待优化：功能已交付，仍有明确的质量、体验或维护改进项。

| -------------------------------- | ------------------------------------------------------------------ | ------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 用户端 apps/user                 | Vue、Quasar、TypeScript 骨架与只读安装身份展示                     | 开发中 | GET /public/config 返回数据库中的系统身份，名称和代币信息随安装配置显示                                                                                                                             |

| 管理后台 apps/admin              | 初始化/迁移状态引导、登录、概览工作台、权限主布局和分页表格组件    | 开发中 | 初始化检查使用 /init；登录后默认进入根路由概览页；管理员、系统菜单、角色 CRUD 和系统设置可用；表格支持快捷/高级搜索、刷新、分页、插槽及加载/空/错误状态                                             |
